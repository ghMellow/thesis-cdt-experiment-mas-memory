# docs/artefatti/

Caricato da solo quando si lavora su file di questa cartella.

- Pagine HTML della documentazione del sistema (una per argomento, ingresso `index.html`), per co-autori e lettori della tesi che non conoscono il sistema.
- **Prima di** scrivere o modificare una pagina → leggi `DESIGN.md` (convenzioni delle pagine).
- Il confronto delle corse non si scrive a mano: lo genera `poetry run python -m utils.generate_mega_comparison --html docs/artefatti/11_confronto.html`.
